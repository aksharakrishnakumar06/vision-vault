# SnapGrid


SnapGrid is a responsive image search web application designed to help users quickly discover high-resolution visual content.


## Features (Part 1 - UI & Scaffold)
**Responsive Layout:** Built with a dark emerald theme and a CSS Grid layout.
**Sticky Header:** Keeps search controls accessible at the top of the viewport.
**Category Chips:** Offers predefined quick-selection tags.
## Design Decisions
1. **Sticky Header:** Positioned the header as sticky so users do not need to scroll back to the top.
2. **Category Suggestions:** Integrated clickable tag chips directly under the header.
